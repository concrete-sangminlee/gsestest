# bot-state

GSES Notice Bot 이 자동으로 관리하는 상태 브랜치입니다. 직접 수정하지 마세요.

| 파일 | 용도 |
|---|---|
| [state.json](state.json) | 처리한 글·마감·리마인더 기록 (커밋 이력 = 처리 이력) |
| [deadlines.ics](deadlines.ics) | 공지 마감 캘린더 — 구독 주소: https://raw.githubusercontent.com/concrete-sangminlee/gsestest/bot-state/deadlines.ics |
| [feed.xml](feed.xml) | 새 글 Atom 피드 — 구독 주소: https://raw.githubusercontent.com/concrete-sangminlee/gsestest/bot-state/feed.xml |

Google Calendar: 다른 캘린더 + → URL로 추가 → 위 deadlines.ics 주소 입력
